# How AI agents work: the model, the harness, and what you plug in

## intro {hold=1}
Do we know what our AI agents can do on our computers? [#names] Claude, Codex and Hermes now come up in the boardroom. [#five] Five things decide whether they are a gain or a new way in.

## model
First, the model answers and the harness acts. [#model] A model takes in text and gives text back. [#harness] The harness is the program around it. It runs the commands the model asks for, and decides what needs approval. [#ask] So ask which model, which harness, and where our data goes.

## parts
Second, three words you will hear. [#agent] An agent is a model and a harness in a loop. [#skill] A skill is a folder of instructions for one task. [#mcp] An MCP server plugs the agent into mail, tickets or a database. [#power] Each one adds power, and a way to misuse it.

## software
Third and fourth, skills and servers are software. [#hidden] Text can hide in a skill. Invisible characters show nothing on screen, yet models can read them. [#scripts] Scripts in a skill are run, not read. [#laptop] An MCP server often runs on a laptop, with the same rights as the AI application that starts it. [#owasp] {OWASP|oh wasp} puts prompt injection at number one in its Top 10 for AI applications.

## limits
Fifth, limits outside the model. [#talk] A model can be talked into things, so safety cannot rest on it saying no. [#sandbox] Recommended: a harness in a sandbox that reaches only the project folder. [#person] Also recommended: risky actions wait for a person. Check whether your agents do this today, because it depends on setup.

## good {hold=1.2}
What good looks like. [#list] One approved list of agents, skills and servers, with an owner. [#review] A person reads every file before install. [#narrow] Each server gets its own narrow token. [#sandbox2] Agents run in a sandbox, and every action is logged.

## first {hold=1.2}
A suggested first step. [#who] Ask which AI agents our people use, and who chose them. [#list2] Then consider one approved list, with settings fixed centrally.

## outro {hold=2}
Agents are safe because of limits around the model. [#keep] Approve the harness, not only the model.
