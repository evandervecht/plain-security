A model, such as Anthropic's Claude, OpenAI's GPT or Nous Research's Hermes, reads text and writes text. On its own it cannot open a file. The harness is the program around it. It gives the model tools, runs the commands the model asks for, and decides what needs your approval. Claude Code is Anthropic's harness, Codex is OpenAI's, and Hermes Agent is an open-source harness from Nous Research that works with many models.

Business impact: the model decides what to try; the harness decides what is allowed. Most of the security lives in the harness and its settings: which folders, which commands, which network. Claude, and the GPT models behind Codex, run as an online service at their vendor. Hermes models can be downloaded and run on your own servers, so you decide where data goes but also patch them yourself. The same model can be safe in one setup and dangerous in another. So it is worth asking two questions: which model, from which provider, and where does our data go? And which harness, with which permissions?

An agent is a model and a harness in a loop: it plans, acts, looks at the result and tries again until the task is done. A skill is a folder with instructions, and often scripts, that teaches the agent one task. An MCP server connects the agent to another system, such as a calendar, a ticket system or a database. The MCP project compares it to a USB-C port for AI.

Business impact: Anthropic's documentation describes a skill in levels. Level 1, its name and description, is always loaded. Level 2, the instructions, loads when a task matches. Level 3, the scripts, is run, and only the output reaches the model. Every skill and server widens what the agent can do, and what it can be tricked into doing. They are software your teams install, and worth treating that way.

Een agent is een model en een harness in een lus: hij plant, handelt, bekijkt het resultaat en probeert opnieuw tot de taak klaar is. Een skill is een map met instructies, en vaak scripts, die de agent één taak leert. Een MCP-server koppelt de agent aan een ander systeem, zoals een agenda, een ticketsysteem of een database. Het MCP-project vergelijkt het met een USB-C-poort voor AI.

Bedrijfsimpact: de documentatie van Anthropic beschrijft een skill in niveaus. Niveau 1, de naam en beschrijving, is altijd geladen. Niveau 2, de instructies, laadt als een taak past. Niveau 3, de scripts, wordt uitgevoerd, en alleen de uitkomst bereikt het model. Elke skill en server verbreedt wat de agent kan, en waartoe hij kan worden misleid. Het is software die uw teams installeren, en het loont om het zo te behandelen.

Anthropic advises using skills only from trusted sources, and auditing every file in one you did not write. There are two reasons. First, text can hide in plain sight. Unicode tag characters show nothing on screen, yet the AWS Security Blog reports that models can read and act on them (2025). A skill that looks harmless can carry an instruction nobody saw. This is a form of prompt injection. Second, scripts in the scripts/ folder are run, not read. Unless a person opens them, nobody knows what they do.

Business impact: an installed skill works with the agent's rights: your files, your code, often your credentials. A malicious one can send data out or change code, and it looks like normal work. A skill you trust can also change with its next update. OWASP ranks prompt injection first in its Top 10 for AI applications (2025).

Anthropic raadt aan om skills alleen uit vertrouwde bronnen te gebruiken, en elk bestand te controleren in een skill die u niet zelf schreef. Daar zijn twee redenen voor. Ten eerste kan tekst zich in het zicht verbergen. Unicode-tagtekens tonen niets op het scherm, maar volgens de AWS Security Blog kunnen modellen ze lezen en ernaar handelen (2025). Een skill die onschuldig oogt, kan een instructie bevatten die niemand zag. Dit is een vorm van promptinjectie. Ten tweede worden scripts in de map scripts/ uitgevoerd, niet gelezen. Tenzij iemand ze opent, weet niemand wat ze doen.

Bedrijfsimpact: een geïnstalleerde skill werkt met de rechten van de agent: uw bestanden, uw code, vaak uw inloggegevens. Een kwaadaardige skill kan gegevens naar buiten sturen of code wijzigen, en het lijkt op gewoon werk. Een skill die u vertrouwt, kan bij de volgende update ook veranderen. OWASP zet promptinjectie op één in zijn Top 10 voor AI-toepassingen (2025).

Many MCP servers run on the user's own laptop. The MCP specification warns that they run with the same rights as the AI application that starts them. A malicious startup command or package can then run any command, for example to send private keys out. Other servers run online and hold tokens to your systems. A broad token stolen there opens everything it covers.

Business impact: a connector to the finance system or a mailbox is a new door into it, and the agent decides when to open it. What a server returns can also carry instructions: a poisoned ticket or web page can steer the agent. Before approving one, it is worth asking four things. What starts it? What code and scripts does it bring? What may it reach? And who maintains it?

Veel MCP-servers draaien op de eigen laptop van de gebruiker. De MCP-specificatie waarschuwt dat ze dezelfde rechten hebben als de AI-toepassing die ze start. Een kwaadaardige opstartopdracht of een kwaadaardig pakket kan dan elke opdracht uitvoeren, bijvoorbeeld om privésleutels naar buiten te sturen. Andere servers draaien online en bewaren tokens voor uw systemen. Een ruim token dat daar gestolen wordt, opent alles wat het dekt.

THE MODEL SAYING NO IS NOT A CONTROLEEN MODEL DAT NEE ZEGT IS GEEN MAATREGEL

A model can be talked into things; that is what prompt injection means. So protection does not rely on the model saying no. It comes from limits around it. The harness runs in a sandbox that reaches only the project folder. Network access is off or limited to a list. Risky actions wait for a person, and tokens give only what the task needs. OpenAI's documentation, for example, says Codex works inside its workspace by default and asks before going beyond it.

Business impact: with those limits, a tricked agent can do little harm. Without them, it can do anything the user can. Our AI sandbox briefing describes the layers one by one.

Een model kan worden overgehaald; dat is wat promptinjectie betekent. Bescherming hangt dus niet af van een model dat nee zegt. Ze komt van grenzen eromheen. De harness draait in een sandbox die alleen bij de projectmap kan. Netwerktoegang staat uit of is beperkt tot een lijst. Riskante acties wachten op een mens, en tokens geven alleen wat de taak nodig heeft. Volgens de documentatie van OpenAI werkt Codex bijvoorbeeld standaard binnen zijn werkruimte en vraagt het toestemming om daarbuiten te gaan.
